## 1. 核心结论与两阶段路线

**两阶段路线：先零资质成本上线纯广告（IAA），用真实数据决定是否升级主体加内购（IAP）。**

```
阶段一（现在 → 上线）              阶段二（DAU/收入达标后触发）
─────────────────────────          ─────────────────────────────
个人主体入驻微信+抖音               注册公司 + 办版号（重投入，8-15 万/6-12 个月）
软著 + ICP 备案 + 自审报告           加轻内购：去广告档、皮肤直购
纯广告变现 IAA                      或拿数据谈发行商（换版号+买量资源）
零成本、软著下来后 2-3 周可上线      依据：阶段一真实 ARPDAU / 月收入数据决策
```

理由：

1. **IAA 上线门槛极低、免版号**。微信个人主体即可开流量主（累计 UV > 100 即可申请），现金分成 50%；
   抖音个人可入驻，自然流（非投广）广告分成 60%。纯广告游戏两平台都只需 **软著 + ICP 备案 + 自审报告**，不需要版号。
2. **纯广告天花板够高**。微信官方数据：年流水破百万的 IAA 产品超 1400 款，IAA 商业规模年增 30%+；
   停车题材有《挪车冲冲冲》纯 IAA 自然流冲上抖音热门榜第一的先例（2025-12）。
3. **内购的路很重，不急着走**。两平台开内购都要求企业/个体户主体 + 版号（抖音硬性；微信亦硬性）。
   本品类 ARPDAU 天花板有限，先用广告跑数据，避免砸钱办证后发现自然流起不来。

### 1.1 阶段一 vs 阶段二 对比

| 维度 | 阶段一（IAA 纯广告） | 阶段二（IAP 混合变现） |
|---|---|---|
| 开发者身份 | 个人主体，不注册公司 | 必须注册**公司**（版号申请主体要求） |
| 资质 | 软著 + ICP 备案 + 自审报告，**免版号** | 上述全部 + **游戏版号** + 中宣部实名认证接入 |
| 变现方式 | 激励视频/插屏/格子广告 | 广告照收 + 内购（去广告 6 元档、皮肤 1-6 元、失败礼包） |
| 分成到手 | 微信 50% / 抖音 60%（自然流） | 安卓内购 60-80% + 微信首发激励（首 1000 万流水不分成）、iOS 优惠期约 88% |
| 后端 | 不需要（§5） | 需要（支付回调验单发货，用云开发） |
| 投入 | ≈ 0 元（软著加急几百元 + 自己的时间） | 8-16 万一次性 + 每年约 1 万持有成本（§1.3） |
| 触发条件 | 现在 | 上线 3-6 个月后、**月广告收入稳定 2 万+** 才评估 |

### 1.2 阶段二不是必经之路：三条岔路

数据达标后有三个选项，投入产出完全不同：

| 选项 | 投入 | 换来什么 | 适合场景 |
|---|---|---|---|
| A. 自己办公司+版号 | 8-16 万 + 6-12 个月并行运营 | 长期 100% 自主收益 | 数据很硬（月广告 5 万+）且愿意长期做商务运营 |
| B. 谈发行商 | 0 元 | 发行出版号/资质/买量资源，你拿流水 30-70% 分成 | 数据不错但不想办公司、不想碰商务 |
| C. 停在阶段一，深化 IAA | 0 元 | 靠关卡月更 + 内容运营把广告收入做厚 | 多数情况。微信年流水百万级纯 IAA 产品 1400+ 款，IAA 不是过渡形态 |

### 1.3 阶段二投入明细（选 A 时才发生）

| 项目 | 费用（参考） | 说明 |
|---|---|---|
| 版号（大头） | 8-15 万 | 走出版社/代理（个人拿不下）；周期 6-12 个月且**不保证批** |
| 注册公司 + 代账报税 | 注册约 0-1 千 + 每年 2-6 千 | 记账代理行情价 |
| 中宣部实名认证接入 | 自己的开发时间 | IAP 前置条件 |
| 后端（云开发） | 每月几十元起 | 支付回调验单、道具发货 |
| 内购开发 | 自己的时间 | 商店 UI、支付接入、道具/皮肤系统 |
| （可选）买量 | 用利润再投 | 微信买量后综合分成自动升至 85-90%（50% 现金+40% 广告金） |

**决策树**：上线 → 3-6 个月数据 → 月广告 < 2 万：留在阶段一，内容迭代或止损；
月广告 2 万+：按数据强度与个人意愿在 A/B/C 里选。**阶段二是期权，不是计划——现在不为它花一分钱。**

## 2. 平台政策速查（2026-11 现行）

| 项目 | 微信 | 抖音 |
|---|---|---|
| 广告现金分成（自然流） | 50%；创意小游戏 200 万内 70% | 60%；投广场景 90%（2026-11-01 新政） |
| 广告金配赠（仅可用于买量） | IAA 买量 30 天 40% / 180 天 35% 二选一 | Q4 限时：投广 +5% 投放金等滚动激励 |
| 内购分成（安卓） | 60% + 首发 5000 万内不分成等激励 | 一般版 60%；减免版非投广 80% |
| iOS 内购 | 2026-02 全面开放，优惠期到手约 88%（至 2026 底） | 2026-11 新接入苹果渠道（渠道费 12%） |
| 内购门槛 | 企业/个体户 + 版号 + 中宣部实名认证 | 版号硬性；个人主体收款不可委托他人 |
| IAA 资质 | 软著 + ICP 备案 + 自审报告，免版号 | 软著（硬性必填）+ 备案，IAA 免版号 |
| 流量主开通 | 累计 UV > 100 | 入驻后商业化模块申请 |
| 广告结算周期 | 月结（次月出账） | 半月结（1-15 日 / 16 日-月末两期） |
| 月活大盘 | 5 亿+（IAA 4 亿，人均 IPU/时长 +20%） | 约 1.7 亿（2026H1 流水同比 +140%） |

注意：微信「90%/85% 分成」口径 = 50% 现金 + 40%/35% 广告金（广告金只能用于腾讯广告投放）。
本方案零买量，实际到手按 **微信 50% / 抖音 60%** 估算；若开始买量，微信综合分成自动升至 85-90%。

eCPM 量级参考（非官方披露，行业口径，实际以后台报表为准）：

- 微信激励视频：官方竞价刊例核心城市最低出价约 50 元/千次；行业经验值国内休闲小游戏 30-100+ 元
  （iOS 占比高、用户质量好的产品更高）；
- 插屏 ≈ 激励视频一半；原生模板/横幅平均约 5 元，10+ 算优秀；
- 抖音激励视频第三方口径 CPM 约 8-25 元；格式收益排序：激励视频 > 插屏 > 原生 > banner。

## 3. 资质与合规路径

### 3.1 上线前必须办的三件事（两平台通用）

| 事项 | 说明 | 周期/费用（参考） |
|---|---|---|
| **软著** | 两平台硬性必填；抖音备案只认国家版权局证书；同一软著只能绑定一款在线小游戏 | 官方通道约 1-2 个月（费用很低）；代理加急 1-3 周、几百元 |
| **ICP/小游戏备案** | 工信部要求，IAA 也必须有；平台代提交 | 与提审并行，约 1-3 周 |
| **自审自查报告 + 适龄提示** | 内容合规自查文档，平台模板 | 1-2 天自己写 |

已废止/不需要的：文网文（已废止）。版号：仅开内购时需要，IAA 阶段不需要。

**软著办理分步**（中国版权保护中心官网在线申请）：

1. 准备材料：申请表（在线填）、**源代码前后各 30 页**（每页 50 行，不足 60 页全交）、
   软件说明书/操作手册（截图配文字即可）、个人身份证明；
2. 名称建议与游戏名对应（如「停车大师小游戏软件 V1.0」），著作权人写个人（写公司则要求公司主体）；
3. 官方通道提交后等受理 + 发证（约 1-2 个月）；赶时间可在提审前用代理加急（几百元，1-3 周）；
4. 拿到证书前**不要**在平台填「已获得软著」——抖音备案只认纸质/电子证书编号，审核会核验。

**微信注册/提审分步**：mp.weixin.qq.com 注册小游戏账号 → 类目选择（游戏-休闲/模拟，个人主体可选类目受限，
以后台列表为准）→ 适龄提示设置 → 资质审核（上传软著 + 自审报告）→ 版本提审（用 `tools/build_wx.js` 产物，
appid 在 `project.config.json` 替换 touristappid）→ 小游戏备案（平台代提交 ICP）→ 发布 → UV > 100 后开通流量主。

**抖音注册/提审分步**：developer.open-douyin.com 创建小游戏 → 主体信息（身份证正反面 + 个人银行卡，
个人主体收款不可委托）→ 上传软著 → 类目 → 版本提审（`tools/build_tt.js` 产物）→ 备案 → 发布 →
商业化-流量主模块申请广告位。审核实操反馈：快则数个工作日、慢则近 1 个月，**预留 2-4 周**。

### 3.2 主体选择

- **阶段一用个人主体**：两平台均允许个人发布小游戏并开广告变现，结算到个人银行卡（个税代扣）。
  月收入过万后税务开始不划算——这是切阶段二的信号之一。
- **阶段二升级**：个体工商户够微信内购进件门槛，但版号申请主体实际上得是公司（§1.3）。
- **捷径**：数据好但不想办证 → 拿数据谈发行商（发行带版号/资质/买量资源，换 30-70% 分成）。

### 3.3 广告与内容合规红线

- 激励视频**必须用户主动点击触发**，严禁自动播放/诱导误点（违规压 eCPM 甚至封广告权限）；
- 广告不得阻断用户流程、不得诱骗点击（微信流量主运营规范）；
- 插屏展示间隔 ≥ 5 分钟，且绝不出现在驾驶过程中；
- 微信**禁止强制/诱导分享**：「分享后解锁」不可以，「自愿分享」可以；
- 适龄提示必做；IAA 阶段实名与防沉迷由平台侧兜底，IAP 时才需自接中宣部实名系统。

## 4. 变现设计：广告点位与代码映射

### 4.1 点位表

竞品实证的激励视频（RV）价值排序：失败复活 > 结算双倍 > 提示/跳关 > 解锁车辆。
本作无「失败即死」节奏，点位按自身节奏重排：

| 优先级 | 点位 | 设计 | 代码落点 |
|---|---|---|---|
| ⭐1 | 结算双倍 | 通关结算页「看视频 · 奖励翻倍」（星级不翻倍，翻「累计里程/成就」类数值奖励，避免破坏星级评价严肃性） | `js/ui_wx.js` 结算页（README 待办已预留） |
| ⭐2 | AI 示范解锁 | 「看视频观看本关标准答案自动演示」——本作独有高价值点位（solver 现成，驾考学员强需求）；每日赠 1 次免费，后续看视频。**已上线 v1**：结算页按钮（无每日免费次数），`game.startDemo()` | `js/autopilot.js` + H 引导线做成可赠权益 |
| ⭐3 | 关卡包解锁 | basic 免费；advanced/challenge/scenes 星级达标，差 1-2 星可看视频补 | `js/progress.js` 的 `unlockMap` 加广告通道 |
| ⭐4 | 新车/皮肤试用 | 「看视频解锁 SUV/豪车模型一次」（用完即回收，收集向可留「看 3 次永久解锁」） | `js/carModel.js` + 关卡简报页 |
| 5 | 插屏广告 | 仅关卡间隙（进下一关时），间隔 ≥ 5 分钟 | `js/game.js` 关卡切换处 |
| 6 | 原生模板/格子广告 | 选关页、暂停页常驻（微信 `createCustomAd`；抖音 banner/原生） | `js/ui_wx.js` 选关页 |

### 4.2 广告 API 实现要点（`PS.Platform.ads` 抽象层）

微信/抖音接口基本同名同义，与 `platform.js` 现有 host 路由同一套思路：

```
PS.Platform.ads.showRewarded({ onReward, onFail })
  ├─ wx: wx.createRewardedVideoAd({ adUnitId })   单例复用
  ├─ tt: tt.createRewardedVideoAd({ adUnitId })
  └─ web: 直接回调 onReward()（本地可玩 + debug 模式）
```

关键实现细节（两平台一致的经验坑）：

1. **单例 + 预加载**：广告对象全局创建一次，`onLoad` 后提前 `load()` 下一支；
   未加载完成时按钮置灰或隐藏，**不要**点了才创建；
2. **发奖判定**：只在 `onClose(res)` 且 `res.isEnded === true` 时发奖；中途关闭不发；
   个别宿主 `onClose` 无 `isEnded` 字段时按「有 onClose 即发奖」兜底（宁可多发不扣奖，投诉成本更高）；
3. **错误兜底**：`onError` 后隐藏广告入口（或提示「稍后再试」），并 `load()` 重试拉取；
   不要在 error 后立刻自动重弹；
4. **频控器**：本地 storage 记录「上次插屏时间戳 + 当日各类型计数」，插屏 ≥ 5 分钟间隔、
   每日 RV 计数上限（防刷奖），持久化防重启绕过；
5. **adUnitId 分端创建**：微信 mp 后台「流量主-广告位管理」、抖音开发者后台「商业化-广告管理」各建各的，
   配置写在构建脚本入参里（`build_wx.js` / `build_tt.js` 注入），不要硬编码进 `js/` 源码；
6. **测试**：开发者工具有模拟广告组件；`tests/wx_bundle_test.js` / `tt_bundle_test.js` 加广告 mock
   保证离线冒烟不破；`debug_wxui.html` 可加广告按钮的 UI 预览态。

### 4.3 频率与目标

- IPU（人均广告次/日）目标 5-8，上限参考《猪了个猪》调优后 12 次；
- RV 渗透率（当日看过 RV 的 DAU 占比）休闲大盘约 3-5%，选看后完成率 82-95%——按钮文案要写清奖励；
- 先保守上线（IPU 3-4），盯次留不掉再逐步加密，**次留优先于 IPU**。

## 5. 后端与用户体系：不需要（阶段一）

**结论：IAA 阶段零后端、零自建用户体系，纯客户端 + 平台能力即可上线。**

| 需求 | 阶段一方案（零后端） | 说明 |
|---|---|---|
| 用户身份 | 平台 openid（`wx.login` / `tt.login`），无需注册 | 小游戏永远不需要传统「注册/账号密码」；openid 即用户体系。初期甚至可以不调 login |
| 存档 | 本地 storage（`progress.js` 已支持 storage 注入） | 单机休闲游戏标准做法；换设备/清缓存丢档是行业常态，投诉多再上云存档 |
| 好友排行榜 | 平台**开放数据域**（好友关系链数据不出微信/抖音，免服务器） | 微信/抖音均支持：主域写 `setUserCloudStorage`（星级/三星数），开放数据域 canvas 渲染好友榜；这是小游戏社交主回路且零后端 |
| 数据分析 | 平台自带看板（微信数据助手/We 分析 + 流量主报表；抖音小游戏看板 + 变现报表） | 本方案盯的 IPU/渗透率/ARPDAU/eCPM 全部平台后台直接读，无需自建埋点 |
| 广告计费 | 平台侧完成，收入进开发者账户 | 与自有后端无关 |
| 运营开关 | 可选：静态 JSON 远程配置（对象存储/CDN 托管）控制广告频率与活动开关 | 非必须，可等有调优需求再加；改配置不发版 |

**何时需要后端（阶段二触发点，出现任一再上）**：

1. **上 IAP**：虚拟支付需要服务端接收支付回调、验单发货（防伪造）——硬要求；
2. 云存档/跨设备同步需求变多（用户投诉或 DAU 上量后）；
3. 排行榜发实物/虚拟奖励（防刷榜需要服务端校验）；
4. 微信+抖音+App 多端打通同一用户（openid 映射表；注意微信与抖音之间无法自动互通，
   只能靠自愿手机号绑定）。

**届时选型**：不自购服务器，直接用 **微信云开发 / 抖音云**（serverless 云函数 + 云数据库 + CDN），
中小体量月成本几十元起，免运维。绝不提前建设——零买量阶段每分钱都该花在内容上。

## 6. 收益测算（零买量、自然流模型）

### 6.1 公式与变量

```
日广告流水 = DAU × IPU × eCPM ÷ 1000
到手 = 日广告流水 × 分成（微信 50% / 抖音 60%，混合按 55%）
```

行业基准：休闲小游戏 ARPDAU（= 日流水/DAU，毛值）常见 **0.1-0.3 元**，变现设计优秀 **0.5 元+**。

### 6.2 敏感性速查（固定 DAU 2000，毛值/日）

| IPU \ eCPM | 20 元 | 40 元 | 80 元 |
|---|---|---|---|
| 3 | 120 元 | 240 元 | 480 元 |
| 5 | 200 元 | 400 元 | 800 元 |
| 8 | 320 元 | 640 元 | 1,280 元 |

（到手约 × 0.55；可见 eCPM 的杠杆大于 IPU——iOS 用户占比和素材质量直接影响 eCPM。）

### 6.3 DAU 场景表（到手/月，55%）

| DAU | 毛广告流水/日 | 到手/月 | 备注 |
|---|---|---|---|
| 500 | 100-150 元 | 1,650-2,500 元 | 自然流起步 3 个月内常见水位 |
| 2,000 | 400-600 元 | 6,600-9,900 元 | 内容运营起量后 |
| 10,000 | 2,000-3,000 元 | 33,000-49,500 元 | 抖音内容爆量才够得着（赛车类小游戏月增近百万用户） |

诚实预期：零买量的瓶颈在获客不在变现（行业 80% 增长靠买量），需用内容运营替代投放预算——
停车题材是小游戏里少有的天然适合短视频的品类（§7）。

**阶段二决策阈值**：月广告收入稳定 2 万+ → 按 §1.2 三条岔路评估；起不来 → 内容迭代或止损。

## 7. 零买量增长打法

### 7.1 抖音侧（主战场，题材红利）

- **内容流量池**：赛车/改装题材月自然播放 50 亿+，赛车类小游戏月新增近百万用户；
  2025Q4 抖音 IAA 新增用户 35% 来自内容场景（同比 +160%）；
- **自制内容**：每周 3-5 条第一人称录屏，选题清单——
  老小区奇葩车位系列（断头路/柱子旁/两车夹缝）、侧方一把入 POV、倒车影像视角、
  「新手司机第一次侧方停车」剧情向、AI 示范 vs 手动对比向、科目二挂科视角共鸣向；
  结算页接官方「分享录屏有奖」（每日限 5 次）；
- **短视频锚点**：发布视频时挂小游戏组件即点即玩（开发者后台开通）；直播时可挂「小手柄」组件；
- **达人免费分发**：「游戏发行人计划」CPS 按效果结算、**零预付**，在星图/开发者后台报名；
  游戏内可给车辆加编号便于主播互动（《挪车冲冲冲》打法）；
- **关注「畅玩权益卡」**：抖音 2025Q4 测试的新广告模式（CPM +10%、IPU ×3-5、ARPU ×5），
  开放申请后第一时间接入。

### 7.2 微信侧（存量盘，靠留存裂变）

- IAA 用户月活 4 亿、70% 只玩休闲游戏，人均 IPU 与时长仍在 +20%——留存型慢热盘；
- **复访三件套**（全免费，官方口径提升利润 30-50%）：
  ①「添加到桌面」（安卓端开放能力，结算/选关页放轻入口）；
  ②侧边栏回流（接入侧边栏入口并统计回流场景值）；
  ③游戏圈（`wx.createGameClubButton` 挂选关页，UGC 攻略沉淀）；
- 分享合规：自愿分享可以，「必须分享才能继续」不可以（§3.3）；
- 获客钩子：做「驾考学员免费体验关卡包」（科目二侧方停车/倒车入库刚需搜索词），免费引流，
  完整版靠关卡包与车辆试用承接（§4.1 点位 3/4）。

## 8. 数据指标体系（上线后每周看）

| 指标 | 定义 | 目标 | 看板位置 |
|---|---|---|---|
| 次日留存 | 新用户次日语义 | ≥ 30%（休闲合格线 25-35%） | 微信数据助手 / 抖音小游戏看板 |

| eCPM | 按广告位分别看 | RV 显著高于插屏/原生即点位结构健康 | 变现报表 |
| 7 日留存 / 时长 | 内容更新效果 | 关卡包月更后环比不降 | 平台看板 |

调优顺序：**次留不掉 → 才加密 IPU → 再优化点位文案/位置**。留存崩了一切白搭。
