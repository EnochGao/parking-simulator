# 新手司机停车模拟器（ParkMaster 停车大师）设计文档

> 版本：v1.0（2026-09-15）
> 定位：面向新手司机的第一人称停车训练模拟器——"真实车里看到什么，模拟器里就看到什么"。

---

## 1. 项目背景与目标

### 1.1 业务背景
新手司机普遍存在"会开车、不会停车"的问题：
- 驾校教的倒车入库/侧方停车与真实小区车位差异大；
- 老小区车位奇葩：窄路、断头路、柱子旁、两车之间极窄空隙、歪斜车位；
- 真车练习成本高、有剐蹭风险、心理压力大。

### 1.2 产品目标
1. **真实**：第一人称驾驶舱视角，还原真实车内的所有参照物——A 柱、引擎盖、左右外后视镜、车内后视镜、方向盘、仪表、倒车雷达。练模拟器的肌肉记忆可直接迁移到真车。
2. **全场景**：覆盖科目二经典项目 + 老小区奇葩车位，从入门到极限共 10 关。
3. **可量化**：碰撞、停正度（位置/角度偏差）、用时全部量化打分，星级反馈。
4. **低门槛**：键盘即玩，无需安装；辅助系统（引导轨迹、俯视上帝视角、倒车影像）可随开关，逐步"脱辅"。

### 1.3 非目标（v1 不做）
- 方向盘外设/手柄力反馈（预留接口，规划 v2）
- 联机对战、剧情模式
- 交通流、行人 AI

---

## 2. 核心玩法循环

```
主菜单 → 选关 → 任务简报 → 第一人称驾驶 → 停入车位（停稳判定）
       → 结算评分（星级/偏差数据/碰撞明细）→ 重试 / 下一关
```

- **通过条件**：车辆四角全部落在车位边界内、车身角度偏差 ≤ 15°、车速为 0 持续约 1.5 秒。
- **失败条件**：累计碰撞 ≥ 5 次强制失败（真实中早剐蹭了）；其余情况均可继续揉库。
- **星级**：★≥90 分　★★≥70 分　★★★≥90 分且碰撞为 0。

## 3. 真实性设计（本作灵魂）

真实车中看到的场景 = 模拟器中的场景。逐项落实：

| 真实车内参照物 | 模拟器实现 | 停车中的作用 |
|---|---|---|
| 左右外后视镜 | 独立相机每帧渲染到纹理，**真实镜像翻转**；V 调节模式可调角度；尺寸/安装位置按 GB 15084（ECE R46）Ⅲ类标定（反射面 ≥170×70mm，玻璃中心伸出车侧约 0.14m，前门导轨处） | 看后轮与库线、两侧车距 |
| 车内后视镜 | 独立相机渲染，真镜面反射（不翻转）；V 调节模式可调角度；按 GB 15084 Ⅰ类标定（风挡顶部居中，反射面 ≥120×40mm） | 观察正后方 |
| A 柱/引擎盖/车头两角 | 舱内 3D 驾驶舱 + 车身外壳可见；细长斜 A 柱（宽 3cm，自车顶角斜落仪表台外角）、下倾引擎盖与雨刮入画 | 判断车头位置、盲区体验 |
| 驾驶舱布局（飞度 GR9） | 复刻第四代飞度座舱：三段抬升式低仪表台（近段 0.80 → cowl 0.95）、**双幅式方向盘**、7 寸**液晶仪表**（实时齿位/车速）、8 寸**悬浮中控屏**、贯穿式空调出风口 + 银色饰条、换挡杆、遮阳板、风挡上沿车顶 | 真实视野基线：高座椅低台面，视线越过台面见引擎盖 |
| 方向盘 | 双幅式，随转向输入旋转（传动比 ≈ 8:1） | 建立转向与车轮的映射 |
| 前后驱动控制 | W 前进 / S 倒车，档位 D/R 随意图自动切换 | 直观的前后油门，降低上手门槛 |
| 松开即刹车 | 松开 W/S 平顺制动至完全停稳 | 真实制动脚感，精准控速 |
| 倒车雷达 | 挂 R 靠近障碍物时蜂鸣 + 距离格 | 距离感训练 |
| 倒车影像 | 挂 R 显示广角后方画面（可关） | 对照真车配置 |
| 转向灯 | Q/E 拨杆 + 灯光闪烁 | 养成习惯（v1 不计分） |

## 4. 车辆与物理模型

### 4.1 车辆参数（本田飞度 第四代 GR9，2021款 1.5L CVT）
| 参数 | 值 |
|---|---|
| 车长 / 车宽 / 车高 | 4.109 m / 1.694 m / 1.537 m |
| 轴距 / 前·后轮距 | 2.53 m / 1.48 m · 1.465 m |
| 轮胎 | 185/60 R15（滚动半径 ≈0.30 m） |
| 整备质量 / 动力 | 1088 kg / L15BU 1.5L 自吸 96kW(131Ps)·155N·m，CVT 前驱 |
| 最大前轮转角 | 36°（由最小转弯半径 4.9m 反推；方向盘 ±270°） |
| 前进极速 / 倒车极速 | 15 km/h / 10 km/h（小区场景限速） |
| 加速度 / 制动减速度 | 3.0 m/s² / 6.0 m/s²（松开 W/S 即按制动减速度停车） |

### 4.2 运动学模型
采用**运动学自行车模型（Kinematic Bicycle Model）**——低速泊车场景的标准模型：
```
θ̇ = v / L · tan(δ)      （θ 航向角，δ 前轮转角，L 轴距）
ẋ = v · cosθ,  ẑ = v · sinθ
```
- 倒挡 v < 0，航向变化自然反向（与真车一致）；
- 方向盘打满需约 0.7 秒（转向速率限制），模拟真实打轮节奏；
- 松开方向键**保持当前转角**（不自动回正），反打方向即可回正——贴合真实驾驶与驾校"打几圈回几圈"的习惯；
- **倒车蠕行**：轻点 S 保持在 1.4km/h 蠕行速度，按住 0.6s 后经常规加速度平滑拉起到倒车极速（无阶跃）；蠕行钳制只限加速、不回拍已有后溜速度（后溜中松开再按 S 不顿挫）——模拟自动挡蠕行，提供泊车低速精细控制；
- **碰撞计数冷却**：同一次顶蹭（1s 内的连续接触）只计 1 次碰撞，避免"反弹→再蹭"被重复惩罚；
- 静止时打轮只转方向盘/前轮，车身不动（符合真实）。

### 4.3 碰撞检测
- 一切碰撞体投影为 2D **OBB（有向包围盒）**，车辆与障碍物均为矩形；
- 使用 **SAT（分离轴定理）** 精确判定任意旋转矩形相交；
- 碰撞响应：车速衰减反弹（v × −0.3）、碰撞计数 +1、画面红闪 + 撞击音效；
- 车身四角 = 车辆 OBB 四角，同时用于"完全入库"判定。

## 5. 场景与关卡设计（10 关，难度递进）

场地统一为"老小区"风格：柏油路面、砖楼、单元门、树、灯杆、垃圾桶、方柱、停放车辆。

| # | 关卡名 | 训练点 | 场景描述 | 难度 |
|---|--------|--------|----------|------|
| 1 | 教学关·空旷车位 | 认识视角/操作/后视镜 | 大空地单个标准垂直车位，辅助全开，文字引导 | ★ |
| 2 | 倒车入库·标准 | 一把倒入 | 车位两侧有车，5m 车道 | ★★ |
| 3 | 侧方停车 | 平行趴车 | 路边平行位，前后有车，右侧是路沿墙 | ★★ |
| 4 | 斜列式车位 | 斜向出入 | 45° 斜列位一排 | ★★ |
| 5 | 直角弯后入库 | 转弯抹角 | 过 L 形直角弯后立即倒库 | ★★★ |
| 6 | 窄巷尽头库 | 多次揉库 | 4m 窄巷断头路尽头的垂直位 | ★★★ |
| 7 | 柱子旁的车位 | 盲区判断 | 垂直位一角紧贴方柱，视线遮挡 | ★★★ |
| 8 | 歪斜车位 | 非标位入库 | 车位相对道路倾斜约 12°，两侧车随位摆放 | ★★★★ |
| 9 | 极限侧方 | 精细修方向 | 前后车间隙仅 5.7m（车身 4.1m） | ★★★★ |
| 10 | 地库柱网终考 | 综合能力 | 地下车库风格，柱间窄位 2.3m，两侧柱子 | ★★★★★ |

每关数据化定义（`js/levels.js`）：出生点、车位（中心/宽长/朝向）、障碍物列表（车/墙/柱/树/垃圾桶）、围墙边界、标准答案路径（教学演示 + 引导线数据源）、教学提示文案。

## 6. 评分系统

| 维度 | 满分 | 计分规则 |
|---|---|---|
| 位置精度 | 40 | 车心与车位中心偏差 ≤0.15m 满分，每超 1cm 扣 1 分 |
| 角度精度 | 30 | 与车位朝向偏差 ≤3° 满分（倒库泊入按 180° 对称计算），每超 1° 扣 2 分 |
| 碰撞 | 30 | 0 次满分；首次 −10，之后每次 −5，扣完为止 |
| 时间奖励 | +10 | 低于标准用时（par）按比例奖励 |

星级：★★★ ≥90 且零碰撞；★★ ≥70；★ ≥50；<50 或碰撞 ≥5 不通过。
结算页展示：得分、星级、位置/角度偏差精确值（cm/°）、碰撞次数、用时、与标准答案路径的对比提示。

## 7. 辅助系统（新手友好，可逐级关闭）

1. **引导轨迹线**（H 键）：地面绘制本关标准答案路径，照着走即可；
2. **俯视上帝视角**（M 键）：正交俯视整车与车位关系，理解几何后切回舱内；
3. **倒车影像**（C 键开关，挂 R 自动弹出画中画）；
4. **倒车雷达**：2.5m 报警半径（对标真车间歇音），蜂鸣频率随距离升高 + HUD 距离格；
5. **教学提示**：每关开始给出要点文案（如"倒库看左镜，库角消失再打方向"）。

## 8. UI / 交互

### 8.1 操作（键盘）
| 按键 | 功能 |
|---|---|
| W / ↑ | 前进（自动切 D 档） |
| S / ↓ | 倒车（自动切 R 档；前进中按 S 先减速再倒车） |
| 松开 W/S | 刹车，平顺停稳 |
| A / D 或 ← / → | 打方向（松开保持角度，不自动回正；反向打轮回正） |
| Space | 手刹（快速刹停） |
| Q / E | 左 / 右转向灯 |
| V | 后视镜调节模式：1/2/3 选左外/右外/车内镜，A·D 左右、W·S 上下调角，V/Esc 完成 |
| H / M / C | 引导线 / 俯视图 / 倒车影像开关 |
| Esc | 暂停菜单 |

### 8.1b 操作（手柄，盖世小鸡等标准布局）
手柄切到 **XInput/PC 模式** 连接电脑，浏览器按 W3C 标准布局识别（`js/gamepad.js` 逐帧轮询
Gamepad API，无需任何驱动或授权弹窗），进入游戏自动生效；键盘与手柄可随时混用，键盘优先。
| 手柄 | 功能 |
|---|---|
| 左摇杆 | 打方向（模拟量：死区 8% + v·|v| 渐进曲线，利于泊车微调；松开保持角度，与键盘一致） |
| RT / LT | 前进 / 倒车（松开即刹车，语义与 W/S 相同） |
| B | 手刹 |
| X / Y | 左 / 右转向灯 |
| LB / RB（按住） | 转头看左 / 右外后视镜（同 Z/X） |
| Back | 引导线开关（同 H）；十字键 ↑/↓ 俯视/倒影（同 M/C）；十字键 ← 后视镜调节模式 |
| Start | 暂停 / 继续 |
| 菜单/简报/结算 | 摇杆或十字键移动焦点（行感知导航），A 确认，B 返回 |
| 后视镜调节模式 | 十字键调角度（同方向键），LB/RB 切换镜子，A 完成 |
| 碰撞 | dual-rumble 震动反馈（Chrome/Edge 支持的手柄生效） |

### 8.2 界面流
- **主菜单**：继续训练（直达下一个未通关卡，有进度时显示）、从头开始、选关、操作说明；HUD 右上角 🔊 音效开关；
- **选关页**：关卡卡片（名称/星级/最佳成绩），线性解锁，`?unlock=1` 可全开练习；
- **任务简报**：训练点 + 提示 → 点击/回车开始；
- **HUD**：档位、时速、计时、碰撞数、雷达格、提示条；仪表风格贴底居中，不遮挡后视镜视线；
- **结算页**：星级动画 + 明细数据 + 重试/下一关；
- 进度存 `localStorage`。

### 8.3 技术架构
```
纯静态站点（零构建、零外部请求、双击 index.html 即玩，完全离线）
├─ index.html            入口（UMD script 加载，file:// 兼容）
├─ vendor/three.min.js   three.js r134（本地化）
├─ js/
│  ├─ config.js    全局参数（车辆尺寸/物理/评分阈值）
│  ├─ physics.js   自行车模型、前后油门、档位自动切换、转向速率 [Node 可测]
│  ├─ collision.js OBB + SAT、车辆四角                [Node 可测]
│  ├─ scoring.js   完成判定与评分                     [Node 可测]
│  ├─ levels.js    10 关数据 + 演示答案脚本            [Node 可测]
│  ├─ autopilot.js 演示脚本执行器（游戏内教学/回归共用）[Node 可测]
│  ├─ textures.js  程序化贴图（柏油/砖墙/窗户…零外部资源）
│  ├─ world.js     关卡数据 → 3D 场景 + 碰撞体（单一数据源）
│  ├─ carModel.js  低多边形车辆外观
│  ├─ cockpit.js   驾驶舱 + 三镜渲染 + 倒车影像相机
│  ├─ assist.js    引导线/俯视图/雷达/声音
│  ├─ hud.js       DOM UI（菜单/选关/HUD/结算/暂停）
│  ├─ gamepad.js   手柄：标准布局轮询/驾驶合并/菜单导航/震动 [纯函数 Node 可测]
│  ├─ game.js      状态机与主循环
│  └─ main.js      引导（URL 参数：selftest / autotest / unlock）
└─ tests/            Node 测试（无需浏览器）
   ├─ run_all.js     单元 + 关卡数据校验 + 自动驾驶回归 + 手柄集成
   └─ server.js      本地静态服务器（E2E 用）
```
URL 参数（测试钩子，亦是功能）：
- `?autotest=<levelId>`：进入关卡并由标准答案自动驾驶（教学演示模式，2 倍速）；
- `?selftest=all`：快速无头跑完全部关卡，输出 PASS/FAIL 结果表并写入 `document.title`（E2E 断言用）。

## 9. 测试计划（全场景覆盖）

### 9.1 Node 单元测试（`node tests/run_all.js`）
- **物理**：积分正确性、转向限幅与松开保持（holdSteer 不自动回正）、倒车航向反向、松开油门刹车停稳、档位自动切换、极速限制、停稳判定；
- **碰撞**：SAT 平行/旋转/相离/相交已知用例、车辆四角计算、边界墙碰撞；
- **评分**：车位内外四角判定、角度对称（倒泊入）、扣分与星级阈值边界、碰撞 5 次失败；
- **关卡数据完整性**：每关字段齐全；车位尺寸 > 车身（可停）；出生点无碰撞；障碍物不与车位重叠；演示脚本存在且合法。

### 9.2 自动驾驶回归（无头 + 浏览器双跑）
同一套 `autopilot.js` 执行每关标准答案：
- Node 无头回归：物理全速模拟，断言每关"能停进去、碰撞 ≤2、≥1 星"→ **关卡可通关性证明**；
- 浏览器 `?selftest=all`：真实渲染环境下再跑一遍，验证渲染、判定、结算联动 → E2E 断言 10/10 PASS。

### 9.3 浏览器端到端（GUI 黑盒）
真实浏览器中验证：菜单渲染、点击进关、键盘驾驶车辆位移、后视镜镜像正确（镜像文字验证）、俯视图/引导线/倒车影像开关生效、手动撞墙计碰撞并红闪、手动入库触发结算与星级、selftest 全绿、无控制台报错。

### 9.4 验收标准
1. `node tests/run_all.js` 全绿；
2. `?selftest=all` 显示 10/10 PASS；
3. 人工 GUI 冒烟用例全部通过、无报错；
4. 双击 index.html 可玩（file:// 兼容）。
