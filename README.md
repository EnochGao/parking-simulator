# 停车大师 ParkMaster · 新手司机停车训练模拟器

第一人称停车训练游戏：真实车中看到什么，模拟器里就看到什么——复刻本田飞度 GR9 座舱的
第一人称视角（双幅方向盘、7 寸液晶仪表、悬浮中控屏、贯穿式出风口、下倾引擎盖与雨刮）、
左右外后视镜、车内后视镜、自动 D/R 档、倒车雷达与倒车影像，专练老小区各类奇葩车位。

## 快速开始

**方式一（最简单）**：双击 `index.html` 即可游玩（完全离线，零外部依赖）。

**方式二（本地服务器）**：

```bash
node tools/server.js 8137
# 打开 http://localhost:8137
```

**方式三（手机/平板）**：手机与电脑连同一 WiFi，电脑上启动 `node tools/server.js 8137`
（默认监听全部网卡，Windows 防火墙首次会询问放行），手机浏览器访问
`http://<电脑局域网IP>:8137`。触屏设备自动显示虚拟驾驶控件：左下 ◀▶ 转向、
右下 ▲前进 ▼倒车 ⏹手刹、右上 ⏸暂停 与 引导线/俯视/倒影开关（与键盘 H/M/C 同路径），
并自动套用触屏画质档（像素比 1.25 / 阴影 1024 / 镜面 RT 降档）保证帧率；
倒车蠕行、松开即刹车、松方向键保持转角等手感与键盘完全一致。竖屏可玩，
横幅会提示横屏视野更佳。

## 操作

| 按键 | 功能 |
|---|---|
| W / ↑ | 前进（档位自动切 D） |
| S / ↓ | 倒车（档位自动切 R；轻点蠕行 1.4km/h 精细控速，按住 0.6s 后加速度渐入、平顺拉起（软接合无顿挫）；后溜中松开再按不顿挫；前进中按 S 先减速再倒车） |
| 松开 W/S | 刹车，平顺停稳 |
| A D / ← → | 打方向（松开保持角度不自动回正；反向打轮回正） |
| Space | 手刹 |
| Q / E | 左 / 右转向灯 |
| V | 后视镜调节模式：1/2/3 选左外/右外/车内镜，A·D 左右、W·S 上下调角，V/Esc 完成 |
| Z / X（按住） | 转头看左 / 右外后视镜 |
| H | 引导轨迹线（标准答案路径）开关 |
| M | 俯视上帝视角开关 |
| , / .（俯视时） | 镜头左旋（画面逆时针）/ 右旋（顺时针），按住持续；也可直接拖拽画面旋转、触屏双指拧动 |
| R（俯视时） | 镜头回正对齐车头，恢复自动跟随（手动旋转后自动跟随暂停，HUD 显示"俯视·手动 R回正"） |
| C | 倒车影像开关（挂 R 显示） |
| 🔊（HUD 右上角） | 音效开关 |
| Esc | 暂停 |

📱 **触屏（自动检测）**：虚拟按键布局见"快速开始·方式三"，与键盘同一语义
（倒车放右下最外侧——泊车主操作）；后视镜调节（V）为键盘/手柄专属。

## 手柄（盖世小鸡等）

手柄切换到 **XInput / PC 模式**（盖世小鸡多数型号按住 X+Home 连接，或用侧面的模式开关切换）
后通过 USB / 蓝牙 / 2.4G 连接电脑，浏览器会按标准布局识别，进入游戏自动生效，屏幕上方提示
"手柄已连接"。碰撞时手柄会震动（Chrome/Edge 支持）。菜单、简报、结算、暂停界面均可用手柄操作。

| 手柄 | 功能 |
|---|---|
| 左摇杆 | 打方向（模拟量随偏幅渐增，利于泊车微调；松开保持角度不自动回正） |
| RT / LT | 前进 / 倒车（松开即刹车；前进中按 LT 先减速再倒车） |
| B | 手刹 |
| X / Y | 左 / 右转向灯 |
| LB / RB（按住） | 转头看左 / 右外后视镜（俯视时改为旋转镜头：LB 画面逆时针 / RB 顺时针） |
| Back（Select） | 引导轨迹线开关 |
| 十字键 ↑ / ↓ | 俯视上帝视角 / 倒车影像开关 |
| 十字键 ← | 后视镜调节模式：十字键调角度，LB/RB 切换镜子，A 完成 |
| Start | 暂停 / 继续 |
| 菜单中 | 左摇杆/十字键移动焦点，A 确认，B 返回 |

键盘与手柄可随时混用，键盘输入优先。

## 关卡（15 关，难度递进）

关卡数据按章拆分在 `js/levels/*.js`（构造器 `js/level_kit.js`，聚合 `js/levels.js`），新增关卡 = 加数据条目 + `node tools/solver.js <id>` 烘焙标准答案。

**第一章·基础篇**
1. 教学·空旷车位 → 2. 倒车入库·两侧有车 → 3. 侧方停车·路边趴车 → 4. 斜列式车位 45°

**第二章·进阶篇**
5. 直角弯后倒库 → 6. 窄巷尽头·靠墙库位 → 7. 柱子旁·视线受限位 → 8. 歪斜车位·非标入库
9. 极限侧方·5.7 米窄位 → 10. 地库柱网·终极考核

**第三章·挑战篇（短视频同款）**
11. 贴墙库·一侧高墙（贴墙看同侧镜控距） → 12. 反向斜位·背向斜列（车头先入不可行，必须倒入）
13. 平移挪库·一字平移（"一斜一正"原地平移贴路沿） → 14. 反推蛇形·倒车绕障（"车尾往哪走，方向盘往哪打"专项） → 15. 窄路晚打·延迟打轮（"库角消失再打死"，练打方向时机与打早/打晚修法）

## 测试（全场景覆盖）

```bash
npm test                  # 单元测试 + 关卡数据校验 + 全关卡自动驾驶回归 + 脉冲积分
                          # + 拐弯真实性门禁（node tests/run_all.js）
npm run audit:mirror      # 后视镜/倒车影像几何审计（GB 15084 / UN R46 / FMVSS 111 对照，37 项）
npm run turn              # 拐弯真实性数值检查（断言化门禁，偏差超阈值即失败退出）
npm run solver            # （调物理参数后）重新求解各关标准答案路径
npm start                 # 启动本地服务器（node tools/server.js 8137）
```

**v1.5 新特性**：触屏模拟量方向盘（抓轮缘旋转与真车同向：顺时针=右转，±270° 满打（与座舱方向盘圈数 1:1）、松手保持、双击回正，替换 ◀▶ 数字键；按住左镜/右镜转头看镜，调镜面板触屏化（V 模式））；
结算界面"复盘回放"（重演本局驾驶全程——固定步长确定性保证轨迹/碰撞/得分一致）；
PWA 离线安装（Chrome/Edge 地址栏安装图标，断网可玩；`node tools/gen_icons.js` 重新生成图标）。

URL 参数：`?level=lv03` 直达关卡；`?autotest=lv03` 观看标准答案演示；
`?selftest=all` 浏览器全关回归；`?mirrortest=1` 后视镜/倒影渲染回读自测；
`?cockpittest=1` 座舱转向联动自测（方向盘↔车轮↔车标）；`?unlock=1` 解锁全部关卡。
浏览器自测结果写入页面标题（如 MIRROR CHECK PASS 28/28）与 window.__*_RESULTS。

## 架构

纯静态站点（零构建、零外部请求）。核心算法（物理/碰撞/评分/一局模拟/规划执行）为
Node/浏览器双端同构模块，`tests/run_all.js` 与浏览器 `?selftest=all` 运行同一套回归。

分层（各模块单一职责，壳只做编排）：

| 层 | 模块 | 说明 |
|---|---|---|
| 规则 | `sim.js` | 一局的步进/碰撞计次/评分/完成/失败——游戏内与无头回归共用同一实现 |
| 物理 | `physics.js` / `collision.js` / `scoring.js` / `pulse.js` | 运动学、OBB+SAT、评分、脉冲积分（演示/规划侧专用积分源） |
| 数据 | `levels.js` / `demo_paths.js` / `progress.js` | 关卡数据；标准答案控制段（工具产物）；进度与存档（解锁链/续玩/落档） |
| 输入 | `input.js` / `gamepad.js` | 可替换输入源（键盘+触屏方向盘模拟量+手柄合并，逐帧录像/复盘回放）与手柄轮询 |
| 表现 | `carRig.js` / `cockpit.js` / `carModel.js` / `world.js` / `assist.js` / `hud.js` | 整车装配与单车表现、座舱、场景、辅助、纯视图 UI |
| 平台 | `platform.js` / `ui.js` / `ui_wx.js` / `sw.js` | 双端平台抽象（浏览器/微信小游戏）、UI 调度与 canvas 实现、PWA 离线 |
| 自测 | `mirror_check.js` / `cockpit_check.js` | 浏览器渲染回读自测（`?mirrortest=1` / `?cockpittest=1`） |
| 壳 | `game.js` / `main.js` | 渲染器/主循环/状态机/界面流转 |

新增玩法（如剧情模式、对战）以"换输入源 + 换规则参数 + 多建一台 rig"接入，无需改动壳层。

设计文档见 [docs/DESIGN.md](docs/DESIGN.md)。
