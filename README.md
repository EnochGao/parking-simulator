# 停车大师 ParkMaster · 新手司机停车训练模拟器

第一人称停车训练游戏：真实车中看到什么，模拟器里就看到什么——驾驶舱视角、左右外后视镜、
车内后视镜、方向盘、自动 D/R 档、倒车雷达与倒车影像，专练老小区各类奇葩车位。

## 快速开始

**方式一（最简单）**：双击 `index.html` 即可游玩（完全离线，零外部依赖）。

**方式二（本地服务器）**：

```bash
node tools/server.js 8137
# 打开 http://localhost:8137
```

## 操作

| 按键 | 功能 |
|---|---|
| W / ↑ | 前进（档位自动切 D） |
| S / ↓ | 倒车（档位自动切 R；前进中按 S 先减速再倒车） |
| 松开 W/S | 刹车，平顺停稳 |
| A D / ← → | 打方向（松开保持角度不自动回正；反向打轮回正） |
| Space | 手刹 |
| Q / E | 左 / 右转向灯 |
| V | 后视镜调节模式：1/2/3 选左外/右外/车内镜，A·D 左右、W·S 上下调角，V/Esc 完成 |
| Z / X（按住） | 转头看左 / 右外后视镜 |
| H | 引导轨迹线（标准答案路径）开关 |
| M | 俯视上帝视角开关 |
| C | 倒车影像开关（挂 R 显示） |
| Esc | 暂停 |

## 关卡（10 关，难度递进）

1. 教学·空旷车位 → 2. 倒车入库·两侧有车 → 3. 侧方停车·路边趴车 → 4. 斜列式车位 45°
5. 直角弯后倒库 → 6. 窄巷尽头·靠墙库位 → 7. 柱子旁·视线受限位 → 8. 歪斜车位·非标入库
9. 极限侧方·5.7 米窄位 → 10. 地库柱网·终极考核

## 测试（全场景覆盖）

```bash
node tests/run_all.js     # 单元测试 + 关卡数据校验 + 全关卡自动驾驶回归
node tools/solver.js      # （可选）重新求解各关标准答案路径
node tools/server.js      # 启动后访问 ?selftest=all 运行浏览器端回归
```

URL 参数：`?level=lv03` 直达关卡；`?autotest=lv03` 观看标准答案演示；
`?selftest=all` 浏览器回归（10/10 PASS 写入页面标题）；`?unlock=1` 解锁全部关卡。

## 架构

纯静态站点（零构建、零外部请求）。核心算法（物理/碰撞/评分/规划执行）为 Node/浏览器
双端同构模块，`tests/run_all.js` 与浏览器 `?selftest=all` 运行同一套回归。

设计文档见 [docs/DESIGN.md](docs/DESIGN.md)。
